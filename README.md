## 🚀 Featured Projects

<details open>
<summary><b>🏎️ Pitwall — Immersive F1 Analytics Platform</b></summary>
<br/>

> Full-stack F1 analytics platform with real-time race replay, live standings, telemetry charts, and multi-driver lap comparisons — letting fans re-experience entire races with accurate positional data for all 20 cars.

| Aspect | Details |
|:-------|:--------|
| **Stack** | Next.js 15 · FastAPI · NumPy · Server-Sent Events · TypeScript · Python |
| **Scale** | ~10,000 pre-rendered frames per race, streamed for all 20 cars simultaneously |
| **Performance** | 60 fps replay achieved from 10 fps source data via NumPy interpolation + 90ms CSS transitions — **zero WebGL** |
| **Architecture** | FastAPI SSE streaming pipeline → Next.js 15 frontend with frame-buffer rendering |
| **Impact** | Eliminated manual data formatting and static visualizations for race analysis |
| **Repository** | [github.com/AKHILESHKOTEGAR](https://github.com/AKHILESHKOTEGAR) |

The hardest problem was smooth motion from sparse telemetry: positional data arrives at 10 Hz, but replay needed to feel broadcast-grade. Pre-rendering NumPy-interpolated frames server-side and letting CSS transitions handle inter-frame tweening delivered fluid 60 fps motion without GPU rendering — keeping the client lightweight enough to run on any device.

</details>

<details>
<summary><b>🍾 Liquor Inventory Management System — Tamper-Proof Audit Platform</b></summary>
<br/>

> Compliance-grade inventory system with a **blind mobile audit scanner** — staff never see expected stock counts, structurally eliminating pre-scan manipulation fraud.

| Aspect | Details |
|:-------|:--------|
| **Stack** | Full-stack · JWT Auth · Mobile Scanner · PDF Generation · Real-Time Dashboard |
| **Scale** | Multi-store architecture with bottle-level granularity and cross-store isolation |
| **Performance** | Real-time discrepancy matrix with calendar view for instant stock-loss detection |
| **Security** | 3-tier RBAC (Owner → Manager → Staff) · JWT + JTI token revocation · snapshot-based stock freezing · cross-store injection blocking |
| **Impact** | Audit data made tamper-proof for government inspectors; automated PDF compliance reports with manager sign-off produce legally verifiable records |
| **Repository** | [github.com/AKHILESHKOTEGAR](https://github.com/AKHILESHKOTEGAR) |

Designed around an adversarial threat model: every audit is a frozen snapshot, every session is revocable at the token level, and the blind-scan workflow removes the information asymmetry that makes inventory fraud possible in the first place.

</details>
